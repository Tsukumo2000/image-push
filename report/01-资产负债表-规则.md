# 资产负债表分析规则

> 金额单位通常为亿元；公司名按原始语音转写稿标注。

## 一、核心概念

1. **时间点/拍照概念（最核心）**：资产负债表是"快照"不是"录像"。它只反映公司在某一天（通常是期末最后一天）的财务状况：一季报=3月31日、中报=6月30日、三季报=9月30日、年报=12月31日。前一天、后一天可能都不一样。利润表和现金流量表才是"时间段"概念。
2. **资产负债表是利润表的驱动力**：资产是驱动利润的核心来源。分析要"先摊开资产负债表"——看它有什么资产、负债；资产决定未来能带来多少利润和现金流。资产负债表"既是利润表的驱动力，也是利润表和现金流的归属"。
3. **体检报告**：资产负债表像一家公司的体检报告，通过它能看透公司的"里子"，预判利润表未来的增长或萎缩。
4. **恒等式**：资产 = 负债 + 所有者权益，隐含三个故事：
   - 资产 → 公司掌握的经济资源（银行存款、应收账款、固定资产、无形资产等），讲"公司的规模和家底有多厚"；
   - 负债 → 公司承担的债务（短期/长期借款、应付账款、应付职工薪酬等），讲"借钱能力和风险有多大"；
   - 所有者权益 → 真正属于股东、不需要还的钱（实收资本=股东投入本金、资本公积、留存收益/未分配利润=赚了没分给股东的部分），讲"赚钱能力和留给股东多少钱"，是公司最扎实的本钱。
5. **科目两面性（硬币理论）**：每个科目在不同环境下都有好的一面和坏的一面。例：存货多=备货足、未来卖得多；行业不景气时存货可能变"废铜烂铁"。负债多=风险高、可能还不上；负债少=可能过于保守、错失扩张（行业井喷时同行借钱扩产、产能是你的好几倍，业绩立马起飞）。
6. **流动/非流动划分**：以"一年"为分界线。流动资产=一年内可变现或使用（货币资金、应收账款、存货等）；非流动资产=长期使用或持有（固定资产、无形资产——专利、品牌，如安踏品牌、英伟达品牌的效应远大于一年）。
7. **三张报表的勾稽关系（生意循环）**：投资筹资循环（先有钱）→ 采购付款循环 → 销售收款循环 → 货币资金循环，对应三张报表之间明确的勾稽关系。
8. **产业链思维/话语权**：任何生意"上有供应商、下有客户"，应收、应付、合同负债、预付等科目直接反映企业在产业链中的话语权强弱。

## 二、重点科目与分析规则

### 1. 货币资金
- **定义/解读**：流动性最强的资产，是最"靠谱"的资产之一；金额高=账上资金充裕、流动性足。
- **判断规则**：货币资金大额提升说明资金充裕，可结合固定资产、存货的扩张判断是否为后续产能投入做准备。
- **案例**：中芯国际货币资金 436亿→556亿（约3个月内），资金充裕。

### 2. 应收账款
- **定义**：客户欠的钱——货已发、收入已确认、客户已收货但还没打款。
- **解读要点**：应收账款高=对下游话语权弱（强势客户在卡账期）；能否收回决定它是否"靠谱"（收得回才靠谱）；金额越大越要看客户是谁。
- **判断规则**：
  - 应收账款大增 → 出货量大增（要与收入同比对上号）；
  - 把应收账款和合同负债对比：客户"欠你的钱" vs "给你的定金"差距越悬殊，话语权越弱；
  - 下游是绝对龙头（如英伟达）时，应收账款高属正常，但明确说明话语权不强。
- **案例**：中际旭创（光模块）应收账款 96亿，为英伟达、谷歌所欠，一季度再增 36亿；亨通光电应收账款 215亿，为三大运营商所欠。

### 3. 存货
- **定义**：库存商品等。
- **解读要点**：存货多=备货足（未来可卖更多）；行业不景气时存货可能变成"废铜烂铁"。两面性最典型。
- **判断规则**：
  - 存货大增 + 上游原材料稀缺（如光芯片，A股主要靠东山精密、元杰科技）→ 战略性囤货、行业高景气；
  - 存货占比大且稳定在高位 → 该行业公司的典型特征（如寒武纪）。
- **案例**：中际旭创存货 126亿→156亿（+30亿，囤光芯片、光模块高景气）；中芯国际存货 255亿→271亿（加大备货）。

### 4. 固定资产
- **定义**：厂房、机器设备等长期资产；制造/重资产企业的绝对核心科目。
- **解读要点**：靠产能驱动利润的公司，固定资产必然是其绝对值最大的科目。
- **判断规则**：固定资产短期大幅增加 = 扩张产能；要判断巨额资本开支是否转化为实际产能、是否有订单支撑（下游愿意付大额定金=产能与良率被认可）。
- **案例**：中芯国际固定资产 1362亿→1536亿（约3个月 +200亿，前期累计资本开支超150亿美元集中转为产能）；亨通光电固定资产约 123亿；鼎龙固定资产 24亿→25亿（占比最大）。

### 5. 在建工程
- **定义**：尚在建设、未转固的产能工程，是未来产能的储备。
- **解读要点**：在建工程大幅上升 = 正在扩张产能。
- **判断规则**：产品需求强且涨价时，在建工程上升说明公司扩产跟上需求；警惕点：产能大幅落地之时可能就是涨价的高峰截止点。
- **案例**：亨通光电在建工程 10.87亿→15亿（光纤需求强、持续涨价，扩产）。

### 6. 商誉
- **定义**：收购溢价——如目标公司值1000万，你花3000万买下，商誉=2000万；"好东西一定要抢，不可能按成本价买"。
- **解读要点**：商誉出现=发生过并购（通常伴随中报/年报的收购事件）。
- **判断规则**：看到商誉要追溯并购对象及业务协同（如设备卖给台积电靠的是被收购的德国子公司）；商誉金额大是潜在减值风险的来源。
- **案例**：罗博特科（光模块设备）商誉 9亿——2025年一季度仅 800万，2025年中报收购德国子公司后形成。

### 7. 无形资产
- **定义**：专利、土地使用权、品牌等。
- **解读要点**：品牌效应是远超一年的长期资产（安踏、英伟达的品牌）；品牌/口碑驱动型公司的利润靠无形资产驱动。

### 8. 应付账款
- **定义**：欠供应商的货款。
- **解读要点**：应付账款高=对上游话语权强（能拖欠供应商的钱）；设备/材料采购型制造企业普遍偏高。
- **判断规则**：应付账款上升 = 对上游话语权增强 + 采购量增加（加大备货）；需匹配行业逻辑。
- **案例**：中芯国际应付账款 56亿→59亿；寒武纪应付票据和应付款项 11亿→16亿。

### 9. 合同负债（预收账款）
- **定义**：客户打来的定金，即预收账款，是未来收入的储备。
- **解读要点**：合同负债高=下游抢着锁定订单、公司话语权强、马上要出货；是订单与景气度最直接的领先信号。
- **判断规则**：
  - 绝对值高 → 订单锁定充分（下游为锁定先进产能预付大额定金）；
  - 从极低值大幅飙升 → 即将放量出货；
  - 与应收账款对比："欠我96亿，定金只打4600万"= 产业链话语权弱。
- **案例**：中芯国际合同负债 42.7亿（寒武纪、华为昇腾锁定产能）；寒武纪合同负债 100万→3.96亿（大幅飙升，马上出货）；中际旭创合同负债 2600万→4600万（绝对值小、环比增速高）；鼎龙合同负债 900万（晶圆厂打的定金）。

### 10. 预付账款
- **定义**：预先支付给上游供应商的款项。
- **解读要点**：预付款大增 = 向上游锁定产能/原材料（如向晶圆厂锁定产能）；同时说明对上游不能赊账、要先给钱。
- **案例**：寒武纪预付账款 7亿→18亿（向中芯国际等晶圆厂锁定产能）。

### 11. 短期借款 / 长期借款
- **定义**：短期借款=一年内要还；长期借款=一年以上。
- **解读要点**：负债代表借钱能力和风险，过多=还款压力大；过少=可能过于保守、没有扩张规划。
- **判断规则**：结合行业景气度判断——朝阳行业井喷期不敢借钱扩张，会受限于产能；同行借钱扩产、业绩起飞。

### 12. 所有者权益（实收资本、资本公积、留存收益/未分配利润）
- **定义**：实收资本=股东投入的本金；未分配利润=公司赚了没分给股东的部分。
- **判断规则**：权益越多=历史上赚钱多或股东追加投资，是最扎实的本钱；公司年年亏损会不断侵蚀权益，最后变成负数→资不抵债→破产风险。

## 三、分析框架与步骤

1. **第一步：看结构（比重）**——把资产负债表科目按比重从高到低排列，先抓出绝对值第一、第二、第三大的科目。绝对值最大的科目决定这家公司靠什么资产驱动未来的收入/利润。
2. **第二步：看同比/环比变化**——对重点科目（尤其是绝对值大的科目）看同比、环比变化。"没有无缘无故的大涨，也没有无缘无故的大跌"；异常大增/大减背后一定反映公司的商业决策。
3. **第三步：与商业模式/行业逻辑互验**——把科目变化与其行业、客户/供应商结构对应，并用不同公司的财报科目互相印证（如中芯国际"固定资产+合同负债大增"与寒武纪"预付账款大增"互相印证同一条产业链逻辑）。
4. **分析视角**：用"破案"的视角看财报——科目变化背后告诉我们这家公司、这个行业正在发生什么。

## 四、风险信号与警惕点

1. 应收账款高企且下游是强势龙头 → 话语权弱、账期被卡；收不回的应收账款就是"不靠谱资产"。
2. 应收账款与合同负债差距悬殊（如欠款96亿 vs 定金4600万）→ 在产业链中话语权弱。
3. 存货高 + 行业转弱 → 存货变"废铜烂铁"，贬值风险；存货需要区分"备货优势"与"积压隐患"。
4. 商誉 → 并购溢价形成的潜在减值风险。
5. 负债过多 → 还款压力大、可能还不上。
6. 负债过少 → 过于保守、可能没有扩张规划，或所在行业已开始萎缩。
7. 所有者权益被逐年亏损侵蚀转负 → 资不抵债 → 破产风险。
8. 固定资产/资本开支大增但无对应订单 → 产能可能闲置。
9. 产品涨价 + 产能扩张 → 涨价高峰可能在产能集中落地时截止。
10. 预付款项高 → 对上游话语权不强（需先给钱）。
11. 资产"家底"要分辨靠谱与虚：货币资金最靠谱、能收回的应收靠谱、存货可能是虚的；资产多不等于质量好。
12. 科目与商业模式错配 → 反常信号（如轻资产行业出现巨额固定资产、无明显并购却出现大额商誉）需深挖。
