# 如何在软件上找财报（操作规则）

> 案例：中际旭创；金额单位：亿元

## 一、查找财报的操作路径

1. 打开行情/炒股软件，搜索目标公司代码或名称。
2. 点开个股页面后，找到左侧 **F10 资料**（部分软件在"更多"菜单）。
3. F10 资料内包含：公司财务情况、股东、高管、分红、公司大事、行业对比等。
4. 优先看 **经营分析**：营业收入结构（产品构成）+ 地区结构（国内外占比）→ 识别公司主营业务到底是什么，不被公司介绍迷惑。
5. 再看 **财务分析**：三张财务报表（资产负债表、利润表、现金流量表）。

## 二、资产负债表查看规则

- 查看方式：按报告期（原始报表）/ 按年度同比（各人喜好）。
- 阅读顺序：流动资产（货币资金、交易性金融资产、应收账款、预付账款、存货）→ 固定资产、在建工程 → 流动负债（短期借款、应付票据和应付账款、合同负债）→ 非流动负债（长期借款）→ 所有者权益。
- **必看"百分比报表"**：把资产负债表按比例划分，找出占比最大的科目——占比最大的科目一定与商业模式一一匹配（如货币资金流动性好、应收账款=客户欠的钱、存货=备货情况、固定资产占比反映重资产程度）。

## 三、利润表查看规则

- 查看方式：
  - 按年度：只保留年报（抹掉季度数据）；
  - 按报告期：一季报/中报/三季报/年报全都有；
  - 单季度：只看每个季度；报告期同比、年度同比、单季度环比。
- **重点：单季度环比**——如果单季度环比持续上升，说明公司在景气赛道持续加速。
- 看原始报表确认：收入、研发投入、销售费用、管理费用、财务费用、资产处置、营业外收支、净利润。

## 四、现金流量表查看规则

- 查看方式：与利润表相同（年度/单季度/报告期/同比/环比）。
- 核心结构：经营活动现金流 → 投资活动现金流 → 筹资活动现金流。
- 百分比数据只用于资产负债表；利润表和现金流量表一般不关注结构占比。

## 五、案例证据（中际旭创，2026年一季度口径）

| 科目 | 金额 | 解读 |
|---|---|---|
| 营业收入结构 | 97% 为光通信/收发光模块 | 主业极其集中 |
| 海外收入占比 | 90% | 出口英伟达、谷歌，与商业模式匹配 |
| 货币资金 | 122 | 流动性好 |
| 交易性金融资产 | 0.1（1002万） | 银行理财，流动性高 |
| 应收账款 | 96.48 | 客户（英伟达等）欠款，账期长 |
| 预付账款 | 14.88 | 预付供应商 |
| 存货 | 156 | 积极备货 |
| 固定资产 | 79 | — |
| 在建工程 | 23 | 扩产中 |
| 短期借款 | 3 多 | 欠银行 |
| 应付票据+应付账款 | 有 | 欠供应商 |
| 合同负债 | 很少 | 英伟达话语权强、预收款少 |
| 单季度环比 | 2025年6月起加速 | 出货量加大、环比持续增长 |

## 六、通用结论

- 绝对值概念优先：先弄清资产负债表中哪个科目占重头戏，再与商业模式对应。
- 不同公司关注不同视角：负债结构（流动 vs 非流动）、地区结构、单季环比等。
