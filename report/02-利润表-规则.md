# 利润表分析规则

> 金额单位默认亿元；案例公司名按原始语音转写。

## 一、核心概念

1. **三大报表及其勾稽逻辑**：上市公司都有三张报表——资产负债表、利润表、现金流量表，背后对应完整的商业链条：投资筹资循环 → 采购付款循环 → 销售收款循环 → 货币资金循环。
2. **资产负债表是"照片"、利润表是"电影"**：
   - 资产负债表是**时间点/照片概念**：记录公司在某一天（每季度最后一天，如12月31日、3月31日）的家底（货币资金、固定资产、存货、合同负债各是多少）。
   - 利润表是**时间段/电影概念**：记录公司在一段时间内（一个季度、半年、一年）到底赚了多少钱、靠什么赚的。
3. **资产负债表是利润表的驱动力**：货币资金、存货、固定资产、商誉、在建厂房等资产负债表科目，是为未来产出和销售提供源源不断驱动力的基础——没有这些家底，就没有未来的收入。
4. **利润表的四个特点**：
   - ① 时间段概念（区别于资产负债表的时点概念）；
   - ② 层层递进、有层次感（收入→成本→毛利→费用→净利润，层层剥开）；
   - ③ 可以"验真假"：需与现金流量表配合做交叉认证，透过报表"破案"，找出与商业逻辑违背、对不上的异常科目；
   - ④ 告诉你公司成长的真相：营业收入、净利润、毛利率大涨（或大幅下降）到底是靠什么驱动的。
5. **利润表科目一定要与公司商业逻辑环环相扣**：收入结构、地区结构、费用结构都应印证这家公司的商业模式。

## 二、利润表结构拆解

```
营业收入（卖东西卖了多少钱，重点看是否靠主业）
    － 营业成本（为了卖东西花了多少钱，看成本控制）
    ＝ 毛利润（产品本身赚了多少钱）
        ／ 营业收入 ＝ 毛利率（产品含金量、溢价能力）
    － 管理费用（管理层工资等）
    － 销售费用（广告、营销、代言带货等）
    － 研发费用（研发人员配置、设备投入）
    － 财务费用（短期/长期借款的利息）
    ＝ 营业利润（主业真实盈利能力，扣除了全部经营性费用）
    ± 营业外收入/支出（与主业无关：卖地、出售固定资产、政府补贴、投资收益、罚款等）
    ＝ 净利润（一段时间内最终落到公司的真金白银，进股东口袋的钱）
```

关键换算关系（讲座原文）：
- 毛利润 = 营业收入 − 营业成本；毛利率 = 毛利润 ÷ 营业收入。
- 营业利润 = 毛利润 − 各项费用（研发、销售、财务、管理费用）。
- 净利润 = 营业利润 ± 营业外收入/支出。

## 三、重点科目与分析规则

### 1. 营业收入
- **定义**：卖东西卖了多少钱；第一栏科目，是收入端起点。
- **解读要点**：① 重点关注是不是靠"卖东西"带来的主业收入；② 看主营业务构成/产品结构占比；③ 看地区分类（国内外占比）。
- **判断规则**：不要看公司的自我介绍，直接看主营业务收入构成来识别公司到底做什么；利润表结构应与商业逻辑环环相扣。
- **案例**：中际旭创主营业务=高端光通信收发模块（光模块），海外占比90%、贡献346.37亿收入，与其商业模式完全匹配；鼎龙股份拆分"半导体业务"与"打印复印耗材"两个板块；通富微电集成电路封装测试占比97.59%。

### 2. 营业成本
- **定义**：为了卖东西花的钱（原材料等）。
- **解读要点**：关注成本控制得好不好。
- **判断规则**：收入大幅提升的过程中，营业成本通常也会大幅上升（需要储备原材料），属正常商业逻辑，应结合收入增速一起看。

### 3. 毛利润 / 毛利率
- **定义**：毛利润 = 收入 − 成本，是这门生意产品本身赚的钱；毛利率 = 毛利润 ÷ 收入。
- **解读要点**：毛利率反映公司产品本身的赚钱能力和竞争力。
- **判断规则**：
  - 毛利率高 = 产品含金量高、溢价能力强（技术更高、性能更好、卖得比同行贵）；
  - 毛利率高低用于同赛道内与同行比较：毛利率更高 → 产品含金量更高；
  - 科技赛道为什么"强者恒强"：享有很高的毛利率，其高毛利来自科技含量。
- **案例**：科技板块（高毛利率）vs 化妆品行业（毛利率高但最后不赚钱，见销售费用）。

### 4. 管理费用
- **定义**：主要给管理层发的工资。
- **解读要点**：公司高速增长期，管理层工资/管理费用也会随之大幅上升。
- **判断规则**：费用绝对值较大的科目需重点关注；结合公司发展阶段看是否合理。
- **案例**：中际旭创管理费用从1.48（上期）提高到4.09（本期），因公司高速起飞、给管理层加工资。

### 5. 销售费用
- **定义**：卖产品花的广告、营销费用。
- **解读要点**：不同行业的销售费用天差地别，是判断商业模式的关键科目。
- **判断规则**：
  - 高销售费用行业（如化妆品）：疯狂砸营销（请李佳琦等大V带货），毛利率看着很高，扣掉营销费用后其实没赚什么钱——"赚吆喝"；
  - 低销售费用行业（如半导体/B2B科技公司）：客户稳定、是B端企业级生意，单点突破客户即可，不用过度曝光，拿实力和产品性能说话——销售费用极低反而说明客户稳定；
  - 一般规律：半导体类公司研发费用非常高但销售费用很低；化妆品正好相反。
- **案例**：通富微电销售费用仅0.78亿（研发约16亿、管理费用6亿）；茅台销售费用16亿且大幅提升（2021年27亿→2025年72亿）。

### 6. 研发费用
- **定义**：研发产品所需的人员配置和设备投入。
- **解读要点**：对半导体等科技公司，是**最核心、最值得先看**的科目。
- **判断规则**：
  - 半导体公司"先看研发费用"：企业肯砸钱研发，才能有成果、才能把产品卖得更贵、形成高壁垒；研发投入逐年加大 = 增长驱动力（研发驱动）；
  - 研发费用是"含科量"的来源：不投入研发就无法形成成果，没有成果就无法卖出高价；
  - 对科技公司，看到大额研发投入是正面信号（国产替代背景下必须靠研发赶超）。
- **案例**：
  - 中际旭创：研发费用从2.9亿（25Q1）增至6.45亿（26Q1），近翻两倍多，因光模块从800G→1.6T→3.2T升级；
  - 鼎龙股份：研发费用从2021年2亿多逐年加到5亿多，支撑其抛光垫全球头部+光刻胶获两大晶圆厂认证；
  - 通富微电：研发投入2021年10亿→约13/11/15→2025年近16亿，年年加大，为先进封装布局。

### 7. 财务费用
- **定义**：借钱（短期/长期借款）产生的利息支出。
- **解读要点**：只要伸手问别人借钱扩张生意，就要付利息，计入财务费用。
- **判断规则**：结合资产负债表借款科目看；属于"开门做生意"的正常成本之一。

### 8. 营业利润
- **定义**：收入把各项成本、费用（产品成本+管理/销售/研发/财务费用）都减掉后得到的最核心利润指标。
- **解读要点**：反映公司主营业务的**真实营业能力**——主业到底赚不赚钱，是不是"赚吆喝"的生意。
- **判断规则**：有些公司牌子打得很响亮，一关起门来算账，把成本费用减完后净利润低得可怜——要在营业利润层面识破。

### 9. 营业外收入（讲座称"偏财收入"）
- **定义**：与主业无关的收入：出售地皮、闲置宾馆等固定资产的卖地收入，政府补贴（科创类公司常见），投资收益、罚款等。
- **解读要点**：营业外收入占比高低用来判断**主业扎不扎实**——占比高说明主业造血能力弱。
- **判断规则**：
  - 研究公司时希望主业占比更高（靠主业自己造血的能力高）；
  - 公司不能一直依托政府补贴（补贴是扶持，目的是让它有一天自力更生）。
- **案例**：新能源汽车国家重金扶持时期，比亚迪净利润里很大一部分来自政府补贴。

### 10. 净利润
- **定义**：一段时间内，把营业收入、成本、费用、营业外收支全部算完之后，最终真金白银落实到的金额。
- **解读要点**：是最终进入股东口袋的钱；利润表层层剥开要逼近的"公司核心质地"。
- **判断规则**：与现金流量表配合做交叉认证，可验证利润真实性。

### 11. 主营业务构成与地区分类（交叉科目）
- 上市公司一般**年报和中报**披露产品结构（A类占比、B类占比）；**一季报、三季报披露信息少**。
- **判断规则**：想了解主营业务构成，建议看**年报**（信息细致程度最大）；同时看按地区划分的收入（海外占比），用地区结构与商业模式互相印证。
- **案例**：中际旭创海外90%；鼎龙股份大陆占比64%→70.28%（半导体卖国内晶圆厂）；通富微电国外收入占比23年74%→24年66%→25年66%（海外占比缩、大陆加单幅度大）；茅台国内95%、海外2.82%。

## 四、分析框架与步骤

1. **第一步：看主营业务构成**（不看出自我介绍）——产品结构占比+地区结构占比，回答"这家公司到底是干什么的"，并用商业逻辑验证。
2. **第二步：看收入与成本（同比对比思维）**——本期与上年同期对比：收入翻了多少倍？成本是否同步上升？用"对比思维"找变化。
3. **第三步：看毛利润/毛利率**——产品本身赚钱能力、溢价能力、含金量。
4. **第四步：看营业利润**——扣掉全部经营性费用后，主业真实盈利能力，识破"赚吆喝"的公司。
5. **第五步：看净利润与营业外收支**——最终到手的钱；拆开政府补贴、卖地、投资收益等非主业项目，判断主业扎实程度。
6. **第六步：按行业特征核对费用结构**——半导体=高研发+低销售；化妆品=低研发+高销售；消费龙头=高销售/管理费用；巨无霸公司=高投资净收益。费用结构与行业商业模式是否匹配。
7. **辅助手段**：① 用年报而非季报看细节；② 利润表与现金流量表交叉验证真假；③ 对收入/净利/毛利率的涨跌，追问"靠什么驱动/什么原因导致"。

## 五、风险信号与警惕点

1. **"赚吆喝"型公司**：品牌响亮、毛利率很高，但把营销等费用扣完后净利润低得可怜（化妆品行业典型）。
2. **营业外收入/政府补贴占比过高**：主业不扎实，不能一直靠补贴活着；补贴本质是扶持到"自力更生"。
3. **报表科目与商业逻辑违背**：科目对不上、逻辑违背商业常识——需与现金流量表交叉认证"验真假"。
4. **增长率异动要找驱动**：收入大涨、净利大涨、毛利率大涨或大幅下降、收入大幅下降，都必须找到驱动原因，不能只看结果数字。
5. **毛利率与费用结构失衡**：高毛利但高费用（最终不赚钱）；或主业收入占比持续下滑（老业务缩减、新业务尚未成势）。
6. **收入与成本不同步**：收入大幅提升时成本、研发、管理费也同步上升属正常；若异常背离需追问原因。

## 七、讲座未涉及的内容

扣非净利润、所得税费用与净利润率、税金及附加、资产减值/信用减值损失、公允价值变动损益、其他收益、每股收益、利润表与现金流量的具体交叉验证方法（讲座预告后续讲解）等未涉及。讲座中"投资收益、政府补贴、罚款"等均按"营业外收支/与主业无关收入"口径讲述，未严格区分会计准则归属。
