# 利润表分析

## 核心概念

1. **时间段/电影概念**：记录一段时间（季度/半年/年）赚了多少钱、靠什么赚的；资产负债表才是时点照片。
2. **资产负债表是驱动力**：货币资金、存货、固定资产、商誉、在建厂房等家底为未来收入提供驱动力。
3. **层层递进**：收入→成本→毛利→费用→净利润，像剥洋葱。
4. **可验真假**：与现金流量表配合交叉认证，"破案"式排查与商业逻辑违背的异常科目。
5. **科目与商业逻辑环环相扣**：收入结构、地区结构、费用结构都应印证商业模式。

## 结构拆解

```
营业收入 − 营业成本 = 毛利润（÷收入 = 毛利率）
毛利润 − 管理费用 − 销售费用 − 研发费用 − 财务费用 = 营业利润
营业利润 ± 营业外收入/支出（补贴、卖地、投资收益等）= 净利润
```

## 重点科目与判断规则

| 科目 | 解读要点 | 判断规则 | 案例（亿元） |
|---|---|---|---|
| 营业收入 | 卖东西卖了多少钱 | 重点看是否靠主业；看产品结构+地区结构；**不看公司自我介绍** | 中际旭创海外90%（346.37）；通富微电封测占97.59% |
| 营业成本 | 卖东西花的钱 | 收入大增时成本同步上升属正常，结合收入增速看 | 中际旭创26Q1成本约105 |
| 毛利率 | 产品含金量、溢价能力 | 高=含金量高、技术强、卖得贵；同赛道比较；科技"强者恒强"来自高毛利 | 科技板块 vs 化妆品 |
| 管理费用 | 管理层工资 | 高速增长期随之上升属正常 | 中际旭创1.48→4.09 |
| 销售费用 | 广告营销 | 高销售费行业（化妆品）"赚吆喝"；低销售费行业（半导体B2B）客户稳定 | 通富微电0.78；茅台27→72 |
| 研发费用 | 研发投入 | **科技公司最核心科目**：投入加大=增长驱动力、壁垒来源；半导体先看研发 | 中际旭创2.9→6.45；鼎龙2→5；通富微电10→16 |
| 财务费用 | 借款利息 | 借钱扩张就要付利息，结合资产负债表借款看 | — |
| 营业利润 | 扣全部经营性费用后的主业盈利 | 识破"赚吆喝"：牌子响但扣费后净利可怜 | 化妆品行业 |
| 营业外收入 | 与主业无关（补贴、卖地、投资收益） | 占比高=主业不扎实；不能一直靠补贴 | 比亚迪新能源期靠补贴 |
| 净利润 | 最终进股东口袋的钱 | 与现金流量表交叉认证验真假 | — |
| 主营构成/地区 | 年报中报披露细、季报信息少 | 看年报；用地区结构与商业模式互相印证 | 茅台国内95%；鼎龙大陆64%→70.28% |

## 六步分析框架

1. 看主营业务构成（产品+地区）→ 回答"公司到底是干什么的"；
2. 看收入与成本（同比对比思维：翻了多少倍？成本是否同步？）；
3. 看毛利率（产品赚钱能力、溢价能力）；
4. 看营业利润（主业真实盈利能力，识破"赚吆喝"）；
5. 看净利润与营业外收支（拆开补贴、卖地、投资收益，判断主业扎实程度）；
6. 按行业特征核对费用结构（半导体=高研发+低销售；化妆品=低研发+高销售；消费=高销售/管理费用；巨无霸=高投资净收益）。

辅助：用年报看细节；与现金流量表交叉验证；对涨跌追问"靠什么驱动"。

## 风险信号清单

- "赚吆喝"型公司（高毛利高费用、净利可怜）
- 营业外收入/补贴占比过高（主业不扎实）
- 报表科目与商业逻辑违背（需与现金流量表交叉认证）
- 增长率异动找不到驱动（大涨大跌必须找到原因）
- 毛利率与费用结构失衡
- 收入与成本不同步（异常背离需追问）
