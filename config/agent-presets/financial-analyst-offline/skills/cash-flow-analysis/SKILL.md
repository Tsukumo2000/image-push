# 现金流量表分析

## 核心概念

1. **流水账/银行卡流水**：逐笔记录一段时期内真金白银的进出；资产负债表是快照、利润表是成绩单。
2. **最难造假**：审计直接调银行流水逐笔核对，是判断公司赚钱能力与生存风险的关键表。
3. **收入 ≠ 现金**：利润表确认收入未必形成现金——赊账挂在应收账款；**销售商品提供劳务收到的现金才是真正拿到手的钱**。
4. **收钱时间差体现话语权**：客户提前/晚/当场给钱，反映公司与客户的话语权对比。
5. **三种钱**：经营活动（日常主业）、投资活动（扩产/理财）、筹资活动（借款/入股/分红）。

## 三大结构

| 结构 | 典型流入 | 典型流出 | 定位 |
|---|---|---|---|
| 经营活动现金流 | 销售商品提供劳务收到的现金 | 购买商品接受劳务支付的现金、职工薪酬、税费 | 最核心、最稳定，安身立命之根本 |
| 投资活动现金流 | 收回投资、处置固定资产 | 构建固定资产无形资产等支付的现金（CAPEX）、投资支付 | 扩张节奏的体现 |
| 筹资活动现金流 | 吸收投资、取得借款 | 偿还债务、分配股利、偿付利息 | 钱从哪里来、如何回报 |

## 重点科目与判断规则

| 科目 | 判断规则 | 案例（亿元） |
|---|---|---|
| 销售商品提供劳务收到的现金 | 真正拿到手的钱；增长=收现能力提升、回款改善 | 中芯国际Q1 194；长川科技12（去年9多） |
| 购买商品接受劳务支付的现金 | **大增≠坏事**，先扒原因：主动囤原材料=看好景气、业绩将爆发 | 长川科技3.61→9.1（翻3倍，经营为负不必慌） |
| CAPEX（构建固定资产等支付的现金） | 逐年加大=真金白银扩产能；成长公司投资现金流长期为负是健康信号；科技公司财报后重点看 | 中芯国际422→538→545→599；茅台Q1仅6 |
| 吸收投资/取得借款收到的现金 | 为资本开支"搞钱"；与投资支出匹配 | 中芯国际38+142 |
| 分配股利/偿付利息 | 筹资长期为负+无借款=纯分红现金牛；借款要付息 | 茅台分红587/709/672 |
| 收回投资/投资支付 | 主业不扩张时做理财（货币资金管理） | 茅台收回投资399/334、投资支付137 |

## 正负号组合情景判断（最核心框架）

| 情景 | 经营 | 投资 | 筹资 | 解读 |
|---|---|---|---|---|
| 现金牛型（健康） | + | − | − | 主业赚钱，扩产/还债 |
| 扩张借钱型 | + | − | + | 主业赚钱+快速扩张，需融资 |
| **危险型** | − | − | + | **主业亏损还扩张，靠借钱续命、失血严重**（典型：光伏） |
| 纯分红型 | + | 少/理财 | − | 成熟现金牛，大额分红 |

## 分析步骤

1. 看三大结构正负号组合（情景判断）；
2. 经营现金流为负先扒原因（收现恶化还是主动囤货）再下结论；
3. 投资活动看扩张节奏（成长=CAPEX加大、为负是常态；成熟=理财投资大）；
4. 筹资活动看资金用途与循环（先筹资→扩张→卖出→还本付息跑通即可；借款与资本开支应匹配）；
5. 把财报与商业模式、行业阶段一一对应（成长赛道筹资强+CAPEX大；消费白马不借钱+大额分红；低迷行业=危险组合）。

## 风险信号清单

- 经营(−)+投资(−)+筹资(+)危险组合（主业丧失造血、靠借款续命）
- 话语权弱：应收账款长期趴账、账期被拉长（收入"虚"）
- 经营现金流为负且不可解释（非囤货而是收现恶化）
- 投资现金流长期为正（卖资产、收缩，与扩张矛盾）
- 筹资依赖度持续升高（利息负担加重）
- 扩张与筹资不匹配（资金链可能断裂）
