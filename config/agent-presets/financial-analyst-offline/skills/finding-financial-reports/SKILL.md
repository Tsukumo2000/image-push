# 如何在软件上找财报

> 注意：本文档与生成的报告中一律使用"行情软件"等通用表述，**不得出现特定软件/品牌名称**；数据核实清单中的来源路径用通用写法（如"行情软件F10路径、官方公告、交易所披露"）。

## 操作路径

1. 打开行情软件 → 搜索公司代码或名称；
2. 点开个股页面 → 左侧 **F10 资料**（含财务情况、股东、高管、分红、公司大事、行业对比等）；
3. 优先看 **经营分析**：营业收入结构（产品构成）+ 地区结构（国内外占比）→ 识别公司主营业务到底是什么，不被公司介绍迷惑；
4. 再看 **财务分析**：三张财务报表（资产负债表、利润表、现金流量表）。

## 资产负债表查看规则

- 查看方式：按报告期（原始报表）/ 按年度同比。
- 阅读顺序：流动资产（货币资金、交易性金融资产、应收账款、预付账款、存货）→ 固定资产、在建工程 → 流动负债（短期借款、应付票据和应付账款、合同负债）→ 非流动负债（长期借款）→ 所有者权益。
- **必看"百分比报表"**：把资产负债表按比例划分，找出占比最大的科目——占比最大的科目一定与商业模式一一匹配（货币资金=流动性好；应收账款=客户欠的钱；存货=备货情况；固定资产占比=重资产程度）。

## 利润表查看规则

- 查看方式：按年度（只看年报）/ 按报告期（一季报/中报/三季报/年报全有）/ 单季度 / 报告期同比 / 年度同比 / 单季度环比。
- **重点看单季度环比**：如果单季度环比持续上升，说明公司在景气赛道持续加速。
- 原始报表确认：收入、研发投入、销售费用、管理费用、财务费用、资产处置、营业外收支、净利润。

## 现金流量表查看规则

- 查看方式与利润表相同（年度/单季度/报告期/同比/环比）。
- 核心结构：经营活动现金流 → 投资活动现金流 → 筹资活动现金流。
- 百分比数据只用于资产负债表；利润表和现金流量表一般不关注结构占比。

## 案例（中际旭创，2026Q1口径，亿元）

## 获取最新财报数据（财经数据 API / 网络公开信息）

分析**新案例**时，优先获取该公司**最新一期**财务报告（含同比基期数据），来源按以下顺序：
**财经数据 API（结构化数据，首选）→ 网络公开信息（web_search，兜底）**。取数后务必注明
数据来源与报告期，并与官方公告交叉核验，不得编造未获取到的数据。

### 方式一：财经数据 API（推荐）

需要 Python 环境（本机已安装 akshare / tushare / pandas）。用 **pwsh** 运行
`python -c "..."` 或先写脚本文件再 `python 脚本.py`，只打印所需关键科目，避免整表输出。

**AKShare（免费、免 token，推荐）**：

```python
import akshare as ak
# 资产负债表 / 利润表 / 现金流量表（东方财富口径，symbol 格式：沪市 SH600519、深市 SZ000001）
bs  = ak.stock_balance_sheet_by_report_em(symbol="SH600519")
pl  = ak.stock_profit_sheet_by_report_em(symbol="SH600519")
cf  = ak.stock_cash_flow_sheet_by_report_em(symbol="SH600519")
# 结果按报告期排列，最新期在头部；取 REPORT_DATE 最新一行，并取上年同期做同比
print(bs[["REPORT_DATE", "TOTAL_ASSETS", "MONETARYFUNDS", "INVENTORY", "CONTRACT_LIABILITIES"]].head(2))
# 财务摘要（同花顺口径，含营收/净利/毛利率/资产负债率等指标）
summary = ak.stock_financial_abstract_ths(symbol="600519", indicator="按报告期")
# 新浪口径备用
sina = ak.stock_financial_report_sina(stock="sh600519", symbol="资产负债表")
```

**Tushare（需注册并配置 token）**：

```python
import tushare as ts
pro = ts.pro_api("你的token")                       # 未配置 token 时改用 AKShare 或网络公开信息
bs = pro.balance_sheet(ts_code="600519.SH", start_date="20240101")   # 资产负债表
pl = pro.income(ts_code="600519.SH", start_date="20240101")          # 利润表
cf = pro.cashflow(ts_code="600519.SH", start_date="20240101")        # 现金流量表
```

### 方式二：网络公开信息（web_search / 页面抓取）

- **新浪财经**：`money.finance.sina.com.cn`（个股财务指标/三大报表页）；
- **东方财富**：`data.eastmoney.com`、`quote.eastmoney.com`（F10 财务分析页）；
- 用 **web_search** 检索，例如"中际旭创 2025年年报 营收 净利润"、"中芯国际 2026Q1 财报"；
- 如需页面细节且 web_search 摘要不足，可用 pwsh 的 `Invoke-WebRequest` 抓取公开页面
  （注意网站反爬限制与数据口径，失败时改用 web_search 或 API）。

### 数据使用原则

1. 新案例一律取**最新报告期** + **上年同期**（同比）两个口径；注明来源与报告期；
2. 优先官方来源（交易所公告、公司定期报告）；API 与公告/新闻口径不一致时以官方公告为准；
3. 交叉核验：API 数据 ↔ web_search/公开信息互相印证，对不上的科目深挖原因；
4. 接口失败时按 AKShare(EM) → 新浪 → 同花顺 → web_search 的顺序换来源；
5. 与 `web_search` 检索配合：用检索确认最新披露事件（业绩预告/快报/重大事项），再用 API 取明细。

## 通用结论

- 绝对值概念优先：先弄清资产负债表中哪个科目占重头戏，再与商业模式对应。
- 不同公司关注不同视角：负债结构（流动 vs 非流动）、地区结构、单季环比等。
