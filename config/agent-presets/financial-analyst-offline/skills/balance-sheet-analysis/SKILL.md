# 资产负债表分析

## 核心概念

1. **时间点/拍照概念**：只反映期末某一天（一季报=3/31、中报=6/30、三季报=9/30、年报=12/31）的财务状况；利润表和现金流量表才是时间段概念。
2. **恒等式**：资产 = 负债 + 所有者权益。资产讲"家底多厚"，负债讲"风险多大"，权益讲"留给股东多少钱"（实收资本=股东本金、未分配利润=赚了没分的钱）。
3. **科目两面性（硬币理论）**：同一科目有好有坏。存货多=备货足但行业不景气时变废铜烂铁；负债多=风险高但过于保守会错失扩张。
4. **流动/非流动**：以一年为界。流动资产=一年内可变现（货币资金、应收账款、存货）；非流动资产=长期持有（固定资产、无形资产/品牌）。
5. **资产负债表是利润表的驱动力**：先摊开资产负债表看资产，资产决定未来利润和现金流。

## 重点科目与判断规则

| 科目 | 解读要点 | 判断规则 | 案例（亿元） |
|---|---|---|---|
| 货币资金 | 最靠谱资产 | 大额提升=资金充裕，结合固定资产扩张判断是否备产能 | 中芯国际436→556 |
| 应收账款 | 客户欠的钱 | 大增=出货量大增（与收入对号）；与合同负债对比看话语权；下游是龙头时高属正常但话语权弱 | 中际旭创96（英伟达/谷歌欠）；亨通光电215 |
| 存货 | 两面性最典型 | 大增+上游稀缺=战略性囤货、行业高景气；行业转弱则贬值 | 中际旭创126→156；寒武纪高位 |
| 固定资产 | 重资产核心 | 短期大增=扩产能；需订单支撑（客户愿付定金=良率被认可） | 中芯国际1362→1536（+200/3个月） |
| 在建工程 | 未来产能储备 | 大幅上升=扩产；警惕产能落地=涨价高峰截止 | 亨通光电10.87→15 |
| 商誉 | 收购溢价 | 出现=发生过并购，追溯并购对象与协同；大额=减值风险源 | 罗博特科0.08→9（收购德国子公司） |
| 无形资产 | 专利、品牌 | 品牌/口碑驱动公司的利润核心来源 | 安踏、英伟达品牌 |
| 应付账款 | 欠供应商的钱 | 上升=对上游话语权增强+采购量增加 | 中芯国际56→59 |
| 合同负债 | 客户定金（预收） | 高=订单锁定充分、马上出货；极低值大幅飙升=即将放量；与应收对比悬殊=话语权弱 | 寒武纪0.01→3.96；中际旭创0.26→0.46 |
| 预付账款 | 预付供应商 | 大增=向上游锁定产能/原材料；对上游要先给钱、话语权不强 | 寒武纪7→18 |
| 短/长期借款 | 一年内/以上要还 | 过多=还款压力；过少=过于保守；结合行业景气判断 | 讲座未给具体金额 |
| 所有者权益 | 实收资本+公积+未分配利润 | 权益多=赚钱多；被亏损侵蚀转负=资不抵债、破产风险 | — |

## 分析三步框架

1. **看结构（比重）**：科目按比重排序，抓出绝对值前三大——最大科目决定靠什么资产驱动利润。
2. **看同比/环比变化**：重点科目异常大增/大减必有其商业决策（扩产、囤货、锁单、话语权变化）。
3. **与商业模式互验**：客户是谁、上游是谁；不同公司科目互相印证（如中芯"固定资产+合同负债大增"与寒武纪"预付账款大增"印证同一产业链）。

## 风险信号清单

- 应收账款高企且下游强势（话语权弱、账期被卡）
- 应收与合同负债差距悬殊（如欠96亿 vs 定金4600万）
- 存货高+行业转弱（贬值风险）
- 大额商誉（减值风险）
- 负债过多（还款压力）/过少（过于保守）
- 权益被亏损侵蚀转负（资不抵债、破产风险）
- 资本开支大增无订单支撑（产能闲置）
- 涨价+扩产（涨价高峰可能在产能落地时截止）
- 预付款高（对上游话语权不强）
- 科目与商业模式错配（反常信号需深挖）
